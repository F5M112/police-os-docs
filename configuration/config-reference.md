# مرجع config.lua

`config.lua` هو الملف الرئيسي لإعدادات Police OS، وهو مخصص لتعديلك (مع `server/config_server.lua` وملفات اللغات في `locales/lang/`). بعد أي تعديل نفّذ في كونسول السيرفر:

```
restart police-os
```

{% hint style="danger" %}
`config.lua` ملف **مشترك**: يصل إلى جهاز كل لاعب، وواجهة التابلت تستلم جدول `Config` كاملًا. لا تضع فيه ويبهوكات ولا توكنات ولا كلمات مرور. الأسرار مكانها `server.cfg`، انظر [ديسكورد والويبهوك](discord.md).
{% endhint %}

## قبل الإطلاق: ما الذي يجب أن تغيّره؟

القيم الافتراضية أمثلة، وبعضها لا يناسب سيرفرك. راجع هذه المفاتيح أولًا:

| المفتاح | لماذا |
|---|---|
| `Config.ServerName` | الافتراضي `Scary Town CFW`، ويظهر أسفل شاشة الدخول. ضع اسم سيرفرك |
| `Config.AdminGrade` و`BossMenu.MinGradeForBoss` | يجب أن يوافقا أعلى رتبة في وظيفة الشرطة عندك (الافتراضي 18). انظر [الرتب والوظائف](ranks-and-jobs.md) |
| `Config.Wings` و`Config.WingsBot` و`Config.Doctor` | إحداثيات الأجنحة والشخصيتين مواقع أمثلة، وموديلات المركبات إضافية (addon) قد لا تملكها |
| `Config.ConvoyBaseCoords` و`Config.ConvoyVehicles` | موقع إخراج الموكب وموديلات مركباته |
| `BossMenu.DefaultWingSpawn` | إحداثيات المثال بعيدة جدًا عن الخريطة المعتادة (x ≈ 10655)، فلا تتركها كما هي |
| `Config.ExtraJobNames` و`Config.ExtraJobTypes` | الافتراضي وظيفة اسمها `hkm` تأخذ صلاحيات الشرطة. إن لم تستعمل هذا فاجعل الجدولين `{}` |
| `Config.TabletItem` | اسم آيتم التابلت في مخزنك |

## اللغة

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `Config.Locale` | `'ar'` | اللغة الافتراضية لمن لم يختر لغة، ولغة الكونسول والسجلات والويبهوك. يجب أن يوجد لها ملف في `locales/lang/` وإلا يرجع المورد إلى `ar` ويطبع تحذيرًا |
| `Config.AllowLanguageSwitch` | `true` | `false` يخفي زر اللغة ويجبر الجميع على `Config.Locale` |
| `Config.Languages` | معلّق | اختياري: قائمة بيضاء مثل `{ 'ar', 'en' }` تحصر اللغات الظاهرة في الزر. اتركه معلّقًا لإظهار كل لغات `locales/lang/` |
| `Config.DebugLocale` | `false` | `true` يطبع في F8 والكونسول كل نص بلا ترجمة، وهو للمطوّرين |

تفاصيل أكثر في [اللغات](languages.md).

## الهوية والمظهر

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `Config.ServerName` | `'Scary Town CFW'` | النص أسفل شاشة الدخول. القيمة الفارغة `''` تُبقي النص المكتوب في `html/index.html` |
| `Config.AppIcons` | `{}` | استبدال أيقونة تطبيق بصورتك، مثل `mdt = 'img/my_mdt_icon.png'` |

التفاصيل في [المظهر والأيقونات](appearance.md).

## الوظيفة والرتب

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `Config.PoliceJob` | `'police'` | اسم وظيفة الشرطة في QBCore. تُستعمل في فحص من هو شرطي، وفي التوظيف والترقية وقبول المتدربين |
| `Config.AdminGrade` | `18` | رتبة الأدمن: يملك صاحبها كل الصلاحيات تلقائيًا، وهو وحده يستطيع منح `system_admin` و`boss_access` |
| `Config.MinGradeForManager` | `10` | أدنى رتبة «مدير»: إدارة الأجنحة وأعضائها وتعيين مسؤوليها، وإعادة فتح التقارير وحذفها |
| `Config.MinGradeForHours` | `9` | **غير مستعمل في الكود حاليًا.** الساعات تُدار بالصلاحيات `add_hours` و`remove_hours` و`reset_hours` |
| `Config.TabletItem` | `'tablet'` | اسم الآيتم القابل للاستخدام الذي يفتح النظام |

## الوظائف الإضافية

وظائف أخرى تأخذ صلاحيات الشرطة (مثل وظيفة قيادة أو إدارة خاصة بسيرفرك):

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `Config.ExtraJobNames` | `{ ['hkm'] = true }` | أسماء الوظائف المعاملة كشرطة |
| `Config.ExtraJobTypes` | `{ ['hkm'] = true }` | أنواع الوظائف (`job.type`) المعاملة كشرطة |
| `Config.ExtraJobsBypassGrade` | `true` | هل تتجاوز هذه الوظائف فحوص الرتبة العادية (إدارة الأجنحة والتقارير وغيرها) |

التجاوز لا يشمل رتبة الأدمن: صلاحيات الأدمن تتطلب رتبة فعلية في وظيفة الشرطة. تفاصيل أكثر في [الرتب والوظائف](ranks-and-jobs.md).

## تطبيق إدارة الشرطة

{% code title="config.lua" %}
```lua
Config.BossMenu = {
    MinGradeForBoss       = 18,
    HireGrade             = 0,
    AllowManageEqualGrade = false,
    DefaultWingSpawn      = vector4(10655.6875, 2465.8157, 24.8047, 76.5637),
}
```
{% endcode %}

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `MinGradeForBoss` | `18` | أدنى رتبة تُعدّ «بوس» وتفتح [تطبيق الإدارة](../usage/boss.md) |
| `HireGrade` | `0` | رتبة الضابط الجديد عند التوظيف |
| `AllowManageEqualGrade` | `false` | هل يتحكم البوس بمن يساويه في الرتبة |
| `DefaultWingSpawn` | `vector4(...)` | نقطة إخراج الأجنحة المنشأة من التطبيق إن ألغى البوس خيار استعمال موقعه |

## اختبار القبول

{% code title="config.lua" %}
```lua
Config.TestSystem = {
    MinGradeToManage = 10,
    PassPercentage   = 71,
    AcceptedGrade    = 0,
    Colors = { Results = 16744272, Accepted = 3066993, Rejected = 15158332 },
}
```
{% endcode %}

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `MinGradeToManage` | `10` | أدنى رتبة تُعدّ «مدير اختبار»: تدير الأسئلة والمدربين وتقبل النتائج وترفضها، وتفتح `/createpolicetest` |
| `PassPercentage` | `71` | نسبة النجاح. تحدد كلمة «ناجح/راسب» في نافذة النتيجة وفي رسالة ويبهوك النتائج، لكنها **لا تمنع** القبول أو الرفض اليدوي |
| `AcceptedGrade` | `0` | رتبة وظيفة الشرطة التي يُعيَّن عليها المتدرب عند `/accepttest` |
| `Colors.Results` | `16744272` | لون رسالة النتائج في ديسكورد (`#FF7F50`) |
| `Colors.Accepted` | `3066993` | لون رسالة القبول (`#2ECC71`) |
| `Colors.Rejected` | `15158332` | لون رسالة الرفض (`#E74C3C`) |

ألوان ديسكورد تُكتب كرقم عشري. لتحويل لون سداسي عشري فاكتب `0xRRGGBB` مباشرة في Lua وسيُقرأ رقمًا، أو حوّله بأي حاسبة. انظر [اختبار الشرطة](../usage/police-test.md).

## Config.MDT

```lua
Config.MDT = {
    MinGrade      = 0,
    IncidentTypes = { 'حادث مروري', 'اعتقال', ... },
    Charges       = { 'قيادة متهورة', ... },
    VehicleFlags  = { 'مطلوبة', 'مسروقة', 'غير مؤمّنة', 'تحت المراقبة' },
}
```

{% hint style="warning" %}
**هذا الجدول غير مستعمل حاليًا** (لا يقرؤه الكود ولا الواجهة). التهم تأتي من أنواع القضايا في قاعدة البيانات، وأنواع إشارات المركبات المقترحة مكتوبة داخل الواجهة، ودخول التطبيق يتحكم به `access_system`. تعديل الجدول لا يؤثر في شيء، وسيُفعَّل أو يُحذف في إصدار قادم. انظر [النظام العسكري](../usage/mdt.md).
{% endhint %}

## Config.Translations

جدول نصوص قديم من الإصدارات السابقة فيه 51 مفتاحًا. **يستعمل الكود منها 16 فقط**، وهي:

| المفاتيح المستعملة | تظهر في |
|---|---|
| `no_permission` | رسالة «لا تملك الصلاحية» عند رفض عملية |
| `wing_given` و`wing_removed` و`already_has_wing` | إشعارات منح الأجنحة وسحبها |
| `manager_added` و`manager_removed` | إشعارات مسؤولي الأجنحة |
| `hours_added` و`hours_removed` | إشعارات الساعات |
| `HEAL_PLAYERS` و`NO_PLAYERS_NEED_HEAL` و`NO_MONEY` و`SUCCESS` | الطبيب |
| `accounts` و`active` و`inactive` و`no_accounts` | تطبيق الحسابات |

* تعديل هذه النصوص ممكن، وتُترجم لكل لاعب بلغته إن وُجدت لها ترجمة في `locales/lang/`.
* باقي المفاتيح (35 مفتاحًا) يمكن تركها أو حذفها دون أي أثر.

## قيم مكتوبة داخل الواجهة

هذه القيم ثابتة في `html/script.js` ولا يغيّرها `config.lua`. إن احتجت تغييرها فتواصل مع البائع، أو عدّل الملف بنفسك إن كان متاحًا لك:

| القيمة | أين تؤثر |
|---|---|
| الرتبة `10` (`MY_GRADE>=10`) | ظهور كل الأجنحة في تطبيق إدارة الأجنحة، وظهور زرّي «إعادة فتح الحالة» و«حذف التقرير» في الـ MDT |
| `HO_GOAL_MIN = 3000` (دقيقة) | هدف الساعات في شريط التقدم: 3000 دقيقة، أي 50 ساعة |

{% hint style="info" %}
هذه القيم تخص عرض الأزرار فقط. السيرفر يتحقق من الصلاحيات بنفسه باستعمال `Config.MinGradeForManager` والصلاحيات، فلا يمكن تجاوز القيود بالتلاعب بالواجهة.
{% endhint %}
