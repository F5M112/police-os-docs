# واجهة HTTP API

واجهة اختيارية تتيح لبوت ديسكورد أو موقعك **إنشاء حسابات الضباط** وتغيير كلمات المرور والتحقق من بيانات الدخول، دون الدخول إلى اللعبة. تتحدث إلى السيرفر عبر طلبات HTTP بصيغة JSON.

{% hint style="info" %}
الواجهة **معطّلة افتراضيًا**. تُفعَّل عند ضبط التوكن `police_api_token` في `server.cfg`.
{% endhint %}

## التفعيل

{% code title="server.cfg" %}
```ini
set police_api_token "ضع-هنا-نصًا-عشوائيًا-طويلًا-جدًا"

ensure police-os
```
{% endcode %}

* استعمل `set` وليس `setr` (انظر [ديسكورد والويبهوك](../configuration/discord.md))، وضع السطر قبل `ensure police-os`.
* التوكن هو كلمة السر الوحيدة للواجهة. اجعله طويلًا وعشوائيًا (32 حرفًا فأكثر)، ولا تشاركه ولا تضعه في كود يصل للمتصفح.

## العنوان والمصادقة

كل الطلبات **POST** إلى:

```
http://عنوان-السيرفر:30120/police-os/<المسار>
```

* `30120` هو المنفذ الافتراضي لسيرفر FiveM، فاستعمل منفذ سيرفرك إن اختلف.
* `police-os` هو **اسم مجلد المورد**، فإن غيّرته فغيّره في الرابط.
* أرسل التوكن كما هو في الترويسة `Authorization` (بدون كلمة `Bearer`)، وأضف `Content-Type: application/json`.

| الحالة | الرمز |
|---|---|
| التوكن غير مضبوط في السيرفر (الواجهة معطّلة) | `503` |
| الطريقة ليست POST | `405` |
| التوكن خاطئ أو مفقود | `401` |
| المسار غير موجود | `404` |
| JSON غير صالح أو حقول ناقصة | `400` |
| محاولات كثيرة | `429` |

{% hint style="success" %}
**اختبار سريع للوصول:** افتح عنوان الواجهة في المتصفح. إن ظهرت `405 Method Not Allowed` فالواجهة تعمل وتصلها. وإن ظهرت `503` فالتوكن غير مضبوط. وإن لم يفتح شيء فالمشكلة في المنفذ أو الجدار الناري.
{% endhint %}

## المسارات

### إنشاء حساب: `/create-account`

| الحقل | القواعد |
|---|---|
| `badge_number` | مطلوب، حتى 20 حرفًا، ولا يتكرر |
| `password` | من 6 إلى 100 حرف |
| `discord_id` | من 17 إلى 19 رقمًا |
| `officer_name` | مطلوب، حتى 100 حرف |
| `admin_id` | معرّف الإداري الذي طلب الإنشاء (حتى 30 حرفًا). يُسجَّل في خانة `created_by` بالشكل `api:<admin_id>`، ويظهر في الويبهوك الأمني |

```bash
curl -X POST "http://SERVER_IP:30120/police-os/create-account" \
  -H "Authorization: YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"badge_number":"A-102","password":"S3cretPass","discord_id":"123456789012345678","officer_name":"محمد أحمد","admin_id":"987654321098765432"}'
```

النجاح (`200`):

```json
{
  "success": true,
  "message": "تم إنشاء الحساب بنجاح",
  "account": { "badge_number": "A-102", "officer_name": "محمد أحمد", "created_at": "2026-11-02 10:00:00" }
}
```

الفشل: `400` (حقل ناقص أو غير صحيح)، `409` (الرقم الوظيفي موجود)، `500` (خطأ في الإنشاء).

* الحساب الجديد يحصل على **الصلاحيات الافتراضية** الثماني، ولا يمنح الـ API أي صلاحية أعلى.
* يصل [الويبهوك الأمني](../configuration/discord.md) رسالة «حساب جديد تم إنشاؤه (API)».

### تغيير كلمة المرور: `/change-password`

يبحث عن الحساب **المفعّل** المرتبط بمعرّف الديسكورد (تصلح لبوت يتيح للضابط تغيير كلمته بنفسه).

| الحقل | القواعد |
|---|---|
| `discord_id` | معرّف ديسكورد الحساب |
| `old_password` | كلمة المرور الحالية |
| `new_password` | من 6 إلى 100 حرف |

* النجاح (`200`): `{"success": true, "message": "..."}` وتُلغى جلسات الحساب المفتوحة.
* كلمة المرور القديمة خاطئة أو لا يوجد حساب مفعّل: `401`.
* الحد: **5 محاولات كل 300 ثانية** لكل معرّف ديسكورد، ثم `429`. وتُصفَّر العدّادات بعد النجاح.
* إن ارتبط أكثر من حساب بالمعرّف نفسه يُستعمل أول حساب فقط.

### التحقق من بيانات الدخول: `/verify-login`

يتحقق من رقم وظيفي وكلمة مرور **دون** فتح جلسة داخل اللعبة (مثلًا لدخول إلى لوحة على موقعك).

| الحقل | القواعد |
|---|---|
| `badge_number` | الرقم الوظيفي |
| `password` | كلمة المرور |

النجاح (`200`):

```json
{
  "success": true,
  "message": "تم التحقق بنجاح",
  "account": { "badge_number": "A-102", "officer_name": "محمد أحمد", "discord_id": "123456789012345678" }
}
```

* الحساب المعطّل أو كلمة المرور الخاطئة: `401` برسالة موحدة.
* الحد: **10 طلبات كل 300 ثانية** لكل رقم وظيفي، ثم `429`. تُحتسب الطلبات الناجحة أيضًا ولا يُصفَّر العدّاد بنجاحها، فلا تستدع المسار عند كل زيارة لصفحة.
* عند النجاح يُحدَّث تاريخ «آخر دخول» للحساب.

## شكل الردود

كل الردود JSON. عند الفشل:

```json
{ "success": false, "error": "وصف الخطأ" }
```

نصوص الأخطاء والرسائل تُكتب بلغة الإدارة `Config.Locale`.

## نصائح أمان

* الواجهة تعمل على **HTTP عادي** على منفذ السيرفر، فالتوكن وكلمات المرور تنتقل دون تشفير إن كان الطلب عبر الإنترنت. الأفضل أن يعمل بوتك على الجهاز نفسه أو الشبكة الخاصة، أو أن تمرّر الطلبات عبر وكيل HTTPS تتحكم فيه.
* لا تستدع الواجهة من متصفح المستخدم أبدًا (فيظهر التوكن لكل من يفتح أدوات المطوّر). اجعل الاستدعاء من خادم أو بوت فقط.
* لا ترسل كلمات المرور إلى قنوات ديسكورد عامة. استعمل رسائل خاصة قصيرة العمر.
* غيّر التوكن عند أي شك بتسريبه (عدّله في `server.cfg` ثم `restart police-os`).
* أمن عام للحسابات: انظر [الأمان](security.md).
