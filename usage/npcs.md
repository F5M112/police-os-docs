# الطبيب وبوت الأجنحة

يضيف السكربت شخصيتين ثابتتين في العالم تتفاعل معهما الشرطة عبر **qb-target**:

* **بوت الأجنحة** لإخراج مركبات الأجنحة، ولفتح نظام الشرطة بدون التابلت.
* **الطبيب** لإنعاش المصابين مقابل رسوم تُخصم من الضابط.

الشخصيتان تُنشآن على جهاز كل لاعب، وهما ثابتتان لا تتحركان ولا تتأذيان، وتُحذفان عند إيقاف المورد. التفاعل معهما **للشرطة فقط**: غير الشرطي لا يرى الخيارات أصلًا. وأسماء الخيارات والقوائم تتبع لغة اللاعب وتتغيّر فور تبديلها من التابلت. وشكل القوائم نفسه يتبع تصميم qb-target وqb-menu المثبّتين عندك.

## بوت الأجنحة

### الإعداد

{% code title="config.lua" %}
```lua
Config.WingsBot = {
    model  = 's_m_y_cop_01',
    coords = vector4(48.2238, -426.8356, 38.3669, 238.8152),
}
```
{% endcode %}

* `model`: موديل الشخصية (أي ped موجود في اللعبة).
* `coords`: الموقع والاتجاه `vector4(x, y, z, heading)`. يُنقص السكربت `1.0` من `z` عند الإنشاء، أي أن الإحداثيات تؤخذ كما يعطيها أمر تحديد موقعك أثناء وقوفك.
* حذف الجدول `Config.WingsBot` بالكامل يلغي الشخصية.

### الخيارات

اقترب من الشخصية (حتى 2.5 متر) ووجّه إليها qb-target. يظهر خياران للشرطة:

| الخيار | وظيفته |
|---|---|
| «فتح نظام الشرطة» | يفتح [التابلت](tablet.md) دون الحاجة إلى آيتم التابلت ودون أنيميشن |
| «أجنحتي / استخراج مركبة» | قائمة أجنحتك ومركباتها |

### إخراج مركبة جناح

1. اختر «أجنحتي / استخراج مركبة». تظهر قائمة «🎖️ أجنحتي» بالأجنحة التي تنتمي إليها. إن لم تكن في أي جناح يظهر «لا تملك أي أجنحة».
2. اختر الجناح (يظهر تحت اسم كل جناح السطر «عرض مركبات هذا الجناح»).
3. تظهر قائمة «🚗 اسم الجناح» بمركباته، ولكل منها «إخراج المركبة». زر «◀ رجوع» يعود لقائمة الأجنحة.
4. اختر المركبة.

يتحقق السيرفر قبل الإخراج من أربعة أمور، وأي فشل يظهر كرسالة خطأ:

| الفحص | الرسالة عند الفشل |
|---|---|
| أنت ضابط شرطة | «هذا الخيار للشرطة فقط!» |
| الجناح موجود | «جناح غير معروف» |
| أنت عضو في الجناح | «لا تملك هذا الجناح» |
| الموديل ضمن مركبات الجناح | «هذه المركبة ليست ضمن مركبات الجناح» |

بعد النجاح تتصرف المركبة بحسب وجود `spawnPoint` للجناح:

| الحالة | ما يحدث |
|---|---|
| للجناح `spawnPoint` | تظهر المركبة في تلك النقطة مع رسالة «تم إيقاف المركبة في موقع الجناح ✅». إن كانت هناك مركبة على بعد 3 أمتار من النقطة تظهر «مكان الإيقاف مشغول! حاول مرة أخرى.» |
| بدون `spawnPoint` | تظهر المركبة على بعد 4 أمتار بجانبك وتُنقل أنت إلى مقعد السائق، مع «تم إخراج مركبة الجناح!» |

* اللوحة تكون `WING` متبوعة بأربعة أرقام عشوائية (مثل `WING4821`)، والمحرك يعمل.
* تحصل على مفاتيحها عبر الحدث `vehiclekeys:client:SetOwner`، فإن كان مخزن مفاتيحك مختلفًا عدّله في `client/main.lua`.
* إن لم يكن الموديل موجودًا في اللعبة (مورد المركبات غير مشغَّل مثلًا) تظهر «الموديل غير موجود: …».

{% hint style="warning" %}
لا يوجد حد لعدد المركبات ولا فترة انتظار بين مرة وأخرى، ولا يحذف السكربت المركبة بعد إخراجها. القيد الوحيد هو انشغال نقطة الإخراج. إن أردت تقييدًا فأضفه بنفسك في `DoSpawnWingVehicle`، أو اعتمد على نظام الجراج لديك.
{% endhint %}

الأجنحة التي ينشئها البوس من [تطبيق الإدارة](boss.md) تعمل مع البوت مثل أجنحة `config.lua` تمامًا. ومن أين تُمنح العضوية؟ من [تطبيق إدارة الأجنحة](wings.md).

## الطبيب

### الإعداد

{% code title="config.lua" %}
```lua
Config.Doctor = {
    model   = 's_m_m_paramedic_01',
    coords  = vector3(-940.59, -2960.07, 12.95),
    heading = 90.22
}

Config.payType      = 'bank'
Config.HealWaitTime = 5
Config.PayAmount    = { Isdead = 250, IsInlaststand = 220 }
Config.DoctorRadius = 15.0
```
{% endcode %}

| المفتاح | المعنى |
|---|---|
| `Config.Doctor.model` | موديل الشخصية |
| `Config.Doctor.coords` | موقعها `vector3`. **يستعملها السيرفر أيضًا** لقياس المسافات، فلا تحذفها |
| `Config.Doctor.heading` | اتجاهها |
| `Config.payType` | حساب الدفع: `'bank'` أو `'cash'` |
| `Config.HealWaitTime` | ثواني الانتظار بين الدفع والإنعاش |
| `Config.PayAmount.Isdead` | رسوم إنعاش المتوفّى (`isdead` في بيانات اللاعب) |
| `Config.PayAmount.IsInlaststand` | رسوم إنعاش «المصاب» (`inlaststand`) |
| `Config.DoctorRadius` | نطاق البحث عن المصابين حول الطبيب |

### طريقة العمل

1. يقف ضابط عند الطبيب (ضمن 10 أمتار منه) ويختار «علاج المصابين».
2. تظهر قائمة «🏥 قائمة المصابين» بكل لاعب مصاب أو متوفٍّ ضمن `DoctorRadius` من الطبيب (وليس منك)، لكل واحد: الاسم والحالة («💀 متوفٍّ» أو «🤕 مصاب») و«التكلفة: $N». وإن لم يوجد أحد يظهر «لا يوجد من يحتاج علاجاً».
3. يختار الضابط المصاب. يتحقق السيرفر من أن الضابط شرطي وقريب من الطبيب وأن المصاب ما زال ضمن النطاق ومصاب فعلًا، ثم:
    * إن لم يملك الضابط المبلغ في الحساب `payType` يظهر «لا تملك مالاً كافياً».
    * يُخصم المبلغ من **الضابط** (لا من المصاب) بسبب `medical-treatment`.
    * ينتظر `HealWaitTime` ثانية.
    * يُرسل الحدث `hospital:client:Revive` إلى المصاب. يصله «الحمد لله على سلامتك»، ويصل الضابط «تم إنعاش المصاب! (دُفع $N)».
    * إن غادر المصاب أو بدّل شخصيته خلال الانتظار يُردّ المبلغ للضابط بسبب `medical-refund`.
4. لا يمكن إنعاش المصاب نفسه مرتين في آن واحد.

{% hint style="danger" %}
الإنعاش يعتمد على حدث `hospital:client:Revive` الخاص بـ `qb-ambulancejob`. إن لم يستقبله مورد في سيرفرك **يُخصم المبلغ من الضابط ولا يُنعَش المصاب**. جرّب هذا مرة قبل الإطلاق، وعدّل اسم الحدث في `server/main.lua` إن كان نظام الإسعاف لديك مختلفًا.
{% endhint %}

الحالات تُقرأ من بيانات اللاعب (`metadata.isdead` و`metadata.inlaststand`) كما يكتبها `qb-ambulancejob`.

## نقل الشخصيتين أو تغييرهما

1. قف في المكان الجديد واحصل على إحداثياتك بأي أداة تحديد إحداثيات تستعملها في سيرفرك.
2. ضعها في `Config.WingsBot.coords` أو `Config.Doctor.coords` و`heading`.
3. أعد تشغيل المورد `restart police-os` وتحقق أن الشخصية على الأرض لا تحتها أو فوقها، خاصة الطبيب لأن `z` فيه يُستعمل كما هو دون تعديل.

{% hint style="info" %}
`config.lua` ملف مشترك يقرؤه السيرفر واللاعبون معًا، فتعديل واحد فيه يكفي للجهتين (السيرفر يقيس المسافة إلى الطبيب بالإحداثيات نفسها).
{% endhint %}
